ValleyChat
 
轻量化游戏开黑即时通讯工具 | WinUI3 C# 客户端 + C++ Cinatra WebSocket 高性能服务端
一款对标KOOK、面向学生游戏社群的私有IM软件，主打低占用原生Windows界面、多麦区语音频道、自定义Bot机器人、完整账号安全体系，支持零成本内网穿透外网联机。
 
📌 项目简介
 
ValleyChat 专为游戏玩家小型社群设计，解决QQ/微信广告繁杂、KOOK加载臃肿、数据不归自己掌控的痛点。
 
- 客户端基于 WinUI3 原生开发，遵循 Windows 11 Fluent 现代化设计，无Electron臃肿依赖，内存占用极低；
- 服务端采用 C++ Cinatra 高性能 WebSocket 框架，支持长连接实时消息、语音流传输；
- 完整私有化部署方案，搭配 Cloudflare Tunnel / FRP 内网穿透，学生无需付费云服务器即可分享给同学联机；
- 内置可拓展Bot生态，可基于原有QQBot改造接入，实现自动回复、群管理、游戏工具等插件能力；
- 全套安全防护体系，双层密码加密、异地登录风控、数据包防重放、XSS过滤、设备指纹反逆向。
 
✨ 核心功能
 
一、基础社交聊天
 
1. 私聊会话、持久化本地聊天记录（SQLite分级存储）
2. 好友添加、好友列表、黑名单系统
3. 新消息 Windows 原生系统弹窗通知
4. 图片缓存机制，图片资源缓存至本地Cache目录
 
二、游戏社群特色（核心差异化）
 
1. 游戏群频道，支持群主自定义创建多语音麦区
2. 独立语音通道，麦克风开关、本地音频采集
3. 游戏标签匹配，按游玩游戏筛选好友、社群
4. 群主权限管控：麦区增删、成员管理、Bot发言开关
 
三、账号与安全体系
 
1. 账号注册/登录，客户端SHA256加盐传输密码，服务端BCrypt哈希持久存储
2. Token会话登录，过期强制下线，支持自动免登
3. 设备指纹校验，拦截逆向客户端伪造登录
4. 登录IP/地点解析，异地登录风险弹窗提醒
5. 数据包时间戳+签名校验，防篡改、防重放攻击
6. 全文本HTML转义过滤，规避视觉钓鱼与跨端XSS风险
7. 本地数据分级存储：永久账号配置 / 可清理图片缓存隔离
 
四、Bot机器人拓展生态
 
1. 支持小号Bot账号独立接入WS协议监听群/私聊消息
2. 内置指令解析， # / / 前缀触发机器人功能
3. 群主可一键关闭群内Bot消息，防止刷屏骚扰
4. Bot限流权限隔离，无法操作群麦区等高敏感功能
 
五、部署能力
 
1. Cloudflare Tunnel 免费隧道，绑定自有域名实现 WSS 加密外网访问
2. 兼容自建FRP内网穿透方案，适合长期稳定多人联机
3. 完整WS通信协议文档，前后端统一JSON数据包交互
 
🛠 技术栈
 
客户端（ValleyClient）
 
- 语言：C# .NET Windows App SDK (WinUI3)
- 架构：标准 MVVM 分层架构
- 存储：SQLite 本地数据库，分级持久化数据
- 网络：原生 WebSocket 封装服务层
- 工具库：系统通知、文件IO、日志工具、XSS过滤、哈希加密工具
- 工程分层：Assets / Enums / Helpers / Models / Pages / ViewModels / Services / Components
 
服务端（ValleyServer，C++）
 
- 语言：C++17
- Web框架：Cinatra 高性能协程HTTP/WebSocket
- 存储：MySQL 用户/群聊数据，ip2region离线IP地址库
- 加密：BCrypt密码哈希、SHA256数据包签名
- 通信：统一JSON数据包协议，区分请求包/服务端推送包

🚀 快速启动指南
 
1. 环境依赖
 
客户端：Visual Studio 2022 / Windows App SDK 1.4+ / .NET 8
服务端：GCC/Clang C++17 / Cinatra 依赖库 / MySQL
 
2. 本地调试流程
 
1. 克隆仓库到本地
2. 客户端补充私有密钥配置文件  SecretConfig.json （仓库已gitignore隐藏，模板见下方）
3. 启动 C++ Cinatra 服务端，监听  127.0.0.1:8080 
4. VS 打开 ValleyClient.sln，编译运行客户端
5. 注册账号，本地内网完成聊天、语音全功能测试
 
SecretConfig.json 模板（自行填充密钥，禁止提交至开源仓库）

📡 通信协议说明
 
全程采用 WebSocket JSON 数据包交互，分为两类数据包：
 
1. 请求包：客户端主动发起（登录、发消息、拉取好友列表），携带Cmd指令、时间戳、签名防重放
2. 推送包：服务端主动下发（新消息、好友上线、异地登录通知、群变更）
 
所有上行文本服务端统一执行HTML转义清洗，双层安全校验，杜绝恶意内容存储与下发。
 
🔒 安全设计亮点（开源核心加分项）
 
1. 传输安全：外网强制WSS加密，禁止明文ws传输
2. 密码安全：客户端加盐哈希传输，服务端BCrypt单向哈希存储，数据库泄露无法反推原始密码
3. 防伪造：设备指纹+数据包签名，拦截逆向客户端伪造登录、篡改请求
4. 风控体系：IP归属地解析、异地登录预警、单IP限流防DoS攻击
5. 本地安全：账号配置AES加密存储，区分永久数据与可清理缓存，不会误删用户凭证
6. 输入过滤：全场景文本XSS转义，杜绝视觉钓鱼欺骗，兼容未来网页端拓展
